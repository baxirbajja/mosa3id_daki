# مساعدي الذكي — نظام حجز المواعيد

مشروع بداية قابل للنشر باستخدام Next.js (App Router) وSupabase/PostgreSQL. الواجهة عربية RTL، التوقيت `Africa/Casablanca`، مدة الموعد 60 دقيقة، والحجز خلال اليوم الحالي والأيام السبعة التالية. يبدأ الجدول الافتراضي من الاثنين إلى السبت 10:00–22:00 والأحد مغلق؛ يمكن تغييره من جدول `weekly_availability`.

> **حالة التنفيذ:** هذه ملفات تطبيق حقيقية، لكنها ليست موقعاً منشوراً بعد. يلزم إنشاء مشروع Supabase وإدخال متغيرات البيئة ونشر التطبيق. لا توجد قاعدة بيانات أو خدمة استضافة مربوطة تلقائياً بهذا الأرشيف.

## التقنية
- Next.js + TypeScript
- Supabase PostgreSQL
- قيد PostgreSQL `EXCLUDE ... tstzrange ... &&` لمنع تداخل الحجوزات المؤكدة على مستوى قاعدة البيانات حتى مع الطلبات المتزامنة.
- واجهة RTL بالعربية.

## التشغيل محلياً
1. ثبّت Node.js 20 أو أحدث.
2. أنشئ مشروعاً في Supabase.
3. من SQL Editor نفّذ `supabase/schema.sql`.
4. انسخ `.env.example` إلى `.env.local` واملأ `NEXT_PUBLIC_SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` و`ADMIN_SETUP_SECRET`.
5. لا تكشف `SUPABASE_SERVICE_ROLE_KEY` في واجهة المتصفح أو المستودع.
6. شغّل:
   ```bash
   npm install
   npm run dev
   ```
7. افتح `http://localhost:3000` للحجز و`http://localhost:3000/admin` للإدارة.

## النشر على Vercel
1. ارفع المجلد إلى مستودع Git خاص بك.
2. استورد المستودع في Vercel.
3. أضف متغيرات البيئة الثلاثة من `.env.example` في إعدادات المشروع.
4. تأكد من تشغيل `supabase/schema.sql` على قاعدة الإنتاج، لا على قاعدة اختبار فقط.
5. انشر، ثم اختبر حجزاً حقيقياً وإلغاءه وطلبات متزامنة.

## تخصيص أيام العمل والاستثناءات
- `weekly_availability.weekday`: الأحد=0، الاثنين=1، ... السبت=6.
- لتغيير يوم أسبوعي، عدّل `is_open`, `start_time`, `end_time`.
- `date_exceptions` يتقدم على الجدول الأسبوعي للتاريخ المحدد. إغلاق استثنائي: `is_open=false`. فتح أو تعديل ساعات: `is_open=true` مع `start_time` و`end_time`.
- الساعات محصورة بين 10:00 و22:00، والموعد لا يتجاوز وقت الإغلاق.

## نقاط يجب إكمالها قبل الاستخدام العام
- لوحة الإدارة الحالية تستخدم رمزاً مشتركاً كحل أولي؛ قبل الاستخدام التجاري يُنصح باستبداله بمصادقة Supabase Auth مع حسابات مدير، وحماية الجلسات ومحدودية المحاولات.
- إضافة واجهة لإدارة أيام الأسبوع والاستثناءات (تُدار حالياً من Supabase SQL/Table Editor).
- إضافة CAPTCHA أو حماية من الروبوتات، تحديد معدل الطلبات، وسياسة خصوصية ومدة الاحتفاظ بالبيانات.
- خدمة SMS/WhatsApp أو البريد غير مدمجة؛ تأكيد الحجز يظهر على الموقع فقط حالياً.
- إنشاء سجل تدقيق إداري، ونسخ احتياطية، ومراقبة أخطاء الإنتاج.
- اختبارات تلقائية للمنطقة الزمنية وتغيير التوقيت الموسمي المغربي، والحجوزات المتزامنة، والإلغاء.

## المسارات
- `app/page.tsx`: صفحة الحجز.
- `app/admin/page.tsx`: لوحة الإدارة الأولية.
- `app/api/availability/route.ts`: عرض الفترات المتاحة.
- `app/api/bookings/route.ts`: إنشاء الحجز.
- `app/api/admin/bookings/route.ts`: عرض الحجوزات وإلغاؤها.
- `lib/schedule.ts`: قواعد التوقيت والجدولة.
- `supabase/schema.sql`: مخطط قاعدة البيانات وقيد منع التداخل.
